## 🧪 Setup

1. Install **XAMPP**
2. Ilagay ang shit na ’to sa `htdocs`
3. Start **Apache** at **MySQL**
4. Open **phpMyAdmin**
5. Import ang SQL at CSV files
6. Open gamit ang `localhost`
7. Check ang database configuration
8. Check ulit kasi baka may bullshit kang nakalimutan
